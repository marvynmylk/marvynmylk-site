# marvynmylk-site

Marvyn Mylk's link-in-bio site. `index.html` is the whole page; photos and covers are in `images/`. Netlify republishes automatically on every push to `main`.

## Rules

- **Always show Marvyn a preview before anything goes live.** Screenshot the changed sections at phone size and send them; push to `main` only after he approves. Pushing publishes the live site immediately. Preferred preview: update the private "Marvyn Mylk Site Preview" artifact (https://claude.ai/artifact/3PbtVw8Duj6k14NpmnVYYb) with the full page so he can scroll it live.
- **Keep the link preview in sync.** `images/share.jpg` is built from `images/profile.webp`, `images/purple-south-cover.jpg` and `images/monster-on-tv-cover.jpg`. Whenever any of those three change (or the headline changes), rebuild it with `python3 tools/make_share_image.py`, check it, and commit it in the same change.
- **The preview image is profile + both covers + headline only.** No subline, labels, handles or footer text.
- **Keep Tyler (Marvyn's partner) out of every image.** He doesn't want to be public. Crop or edit him out of any photo before it goes on the site.
- **No "AI tells" in design:** no small eyebrow labels, source footers, handle footers or page numbers.
- **Sign-up forms** post to Netlify Forms (form name `book-news`). Keep `data-netlify="true"`, the hidden `form-name` input and the `bot-field` honeypot on the sign-up form (one form, at the end of the page). The form asks for email and town (`tools/townsign.py`); on article pages it leads with "Want your town next?", and a small slide-up on a reader's second page fills in and sends that same form, so there is still only one form per page.
- **Every page ends the same way:** the sign-up with floating brand and book chips around Marvyn's photo, then the fine print, then the footer (gradient wordmark traced from the book covers, the slogan "Elections are decided by a handful of votes. Be a voter.", an underlined "View more" link and the site map). Run `python3 tools/page_end.py <page.html>` on every new page. When you add a page, add it to the site map in `tools/footer.py` and to `tools/pages.json` (which puts it on the "Explore North Alabama" story map, as a pin for local pages or a card for statewide ones), then re-run the script on every page and run `python3 tools/sitemap.py` so the new page is in `sitemap.xml`. The script also adds the site menu (`tools/chrome.py`), the styled question cards, and party colors on candidate names in body copy (`tools/candcolor.py`; add new candidates to its D and R lists, full names for anyone whose last name is a common word or place). The same script puts a small candidate face before the first mention of each candidate in every section; photos live in `images/people/` and are mapped in `FACES` in `tools/candcolor.py`. Stacked comparison bars (`.chart.cty`) get a soft blue arrow that fades in from the first bar's split to where later bars landed, then fades out, leaving a faint dashed mark (`tools/shift.py`). The Explore hub (`explore/index.html`) lists every page in `tools/pages.json`; its "Around Alabama" reading list lives in `tools/news.json` (outside reporting, linked and credited, never copied).
- The `og:url` and `og:image` tags use the absolute address `https://marvynmylk.com`. Update them if the site's address changes.
